# Grace Event Coordinator — Second Brain

Transcript-synthesis and event-coordination vault. The authoritative operating spec is **[[CLAUDE.md]]**; always-current procedures live in **/Workflows** (check there before starting any task).

## Map

- **/Transcripts** — meeting transcripts (YAML frontmatter; `unprocessed` → `processed`)
- **/Synthesis** — weekly cross-meeting synthesis notes
- **/Events** — one planning note per event (+ optional Day-Of Planner once active)
- **/Agendas** — agendas drafted ahead of syncs/check-ins
- **/Trackers** — [[Trackers/Open Actions.base]] (over `/Trackers/Actions`, with logs split out to `/Trackers/Action-Logs`), [[Trackers/Events]], [[Trackers/Hours]], [[Trackers/Automation]] (scheduled-task inventory), [[Trackers/Subscriptions]], [[Trackers/Calendar-Window]]
- **/Contacts** — [[Contacts/Vendors]], [[Contacts/Credentials]], and [[Contacts/Phone-Index]]
- **/People** — one note per recurring principal + the [[People/Good Noodles]] roster for everyone else
- **/Workflows** — procedures for every recurring task
- **/Logs** and **/Changelog** — append-only run logs and one-file-per-change history; never read on a normal run
- **/Archive** — superseded files (never deleted)
- **/Raw From Grace** — read-only source material; never edited

## Rules of the house

Never delete (move to /Archive). Never edit transcript bodies except speaker renames. Never write to /Raw From Grace. Don't fabricate. Ask before merging, archiving, or anything destructive.
