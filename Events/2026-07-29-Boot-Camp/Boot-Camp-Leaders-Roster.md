## Roster

Each leader is now its own note under [[Events/2026-07-29-Boot-Camp/Leaders]], with `age_group`, `in_group_chat`, `response`, `interested`, `flagged`, `phone`, `email`, and `rock_note` as standardized properties (all 21 notes vetted 2026-07-04, contact info pulled from Rock where not already known from the SMS thread or Contacts). Open **Boot-Camp-Leaders-Roster.base** in Obsidian for the full filterable/sortable table with views for All Leaders, Interested (Y/N), Young Leaders, Old Leaders, Flagged/Needs Review, and No Response Yet.

`interested` is a simple Y/N derived from their text response: any affirmative reply ("I'm in," "In," a confirmed yes) is Y; silence is N. It's separate from `flagged`/`rock_note`, which are about age-group vetting, not willingness.

The live table below (Dataview) mirrors the Base's "All Leaders" view so you can see it without leaving this note:

```dataview
TABLE
  age_group AS "Age",
  choice(in_group_chat, "✅", "—") AS "In Chat",
  response AS "Response",
  choice(interested, "Y", "N") AS "Interested? (6/22 ask)",
  choice(registered_lunch, "✅", "—") AS "Lunch Reg'd?",
  choice(flagged, "⚠️", "") AS "Flag",
  phone AS "Phone",
  email AS "Email"
FROM "Events/2026-07-29-Boot-Camp/Leaders"
SORT registered_lunch DESC, response DESC
```
