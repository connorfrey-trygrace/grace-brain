## Notes on structure (common across all five)

- **Greeting** → **role-specific duty paragraph** → **Connor's own "successful evening" line** → **account-setup paragraph (with the live login.planningcenteronline.com link)** → **scheduling paragraph** (varies: sign-up for Greeter/Usher/Audio-Visual, opt-out/block-out for Captain/Host) → **first-time-serving orientation line** (Greeter and Usher only — Host and Captain deliberately excluded, since Captain *is* the person a first-timer would be oriented by) → **closing thanks line** → **"Let me know if you have any questions."** → signature (Connor, cell, Grace email).
- Automation caveat: **Host**'s automation lives on the "Evening Connection" team, which also holds an empty "Discussion Leader" position. The trigger is team-wide, not per-position — if Discussion Leader is ever staffed, that person would get the Host email too. Worth revisiting if that position comes into use.
