# 2026-09-23 — Grace Q&A Board (AhaSlides overlay)

- **What:** new bookmarklet that opens a moderator panel over the AhaSlides presenter plus a branded display window for the projector. It reads `presenter.ahaslides.com/api/question/list/?id=<deck>` every 4 s (GET only; it never writes to AhaSlides). You can feature any question, answered ones included, set a question-of-the-night hero, add host cards, and show or hide vote counts.
- **Where:** `Workflows/qa-board/`: `qa-board.js` (source), `build-bookmarklet.py` (regenerates `install.html`), `install.html` (drag-to-bookmarks-bar install page).
- **Why:** the 9/27 QOTN's supporting questions had been marked answered in AhaSlides. AhaSlides has no un-answer or restore control, and answered questions can't be pinned.
- **Caveat:** `/api/question/list` is AhaSlides' internal endpoint, not a public API. If they change it, the panel shows "Can't reach AhaSlides" and the display keeps the last data it had.
