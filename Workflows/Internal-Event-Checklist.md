# 🗓️ Internal Event Checklist

For Grace-organized events built from scratch: World Cup party, boot camps, viewing parties, one-offs.
No Sign Up Genius, no ticket sales — volunteer crew recruited directly.
See [[Workflows/Concert-Checklist]] for external concerts.
Credentials: see [[Contacts/Credentials]]
Contacts: see [[Contacts/Vendors]]

---

## 📌 Phase 1: Once Date Is Confirmed

- [ ] Create event planning note — **Connor**
- [ ] Add to Events Tracker — **Connor**
- [ ] Notify Derek to begin marketing/website once time is locked — **Connor**
- [ ] Determine room configuration (chairs, screens, AV setup) — **Connor + Brian**
- [ ] Confirm venue availability with Brian — **Connor**
- [ ] Email BQ management the event date — **Derek**
- [ ] Reserve production manager / sound tech if needed — **Connor/Joe**
- [ ] Reserve custodian (Alex first, then Jorge/Lilliana) — **Connor**
- [ ] Confirm police/security needed — if yes, Brian requests officers — **Brian**
- [ ] Determine food/concessions plan — **Connor**

---

## 📅 Phase 2: One Month Before

- [ ] Finalize schedule and run-of-show — **Connor**
- [ ] Recruit volunteer crew directly (no Sign Up Genius):
  - [ ] Setup/teardown crew
  - [ ] AV operator
  - [ ] Host/emcee
  - [ ] Food/concessions help
  - [ ] Greeters
- [ ] Confirm food partner or in-house plan — **Connor**
- [ ] Confirm AV/tech setup (screens, projectors, sound) — **Joe/Connor**
- [ ] Create any event-specific signage — **Connor/Jade**
- [ ] Comms/marketing request to Derek — **Connor**

---

## ⏰ Phase 3: One Week Out

- [ ] Follow up with all confirmed volunteers — **Connor**
- [ ] Confirm custodian — **Connor**
- [ ] Confirm food setup window with partner — **Connor**
- [ ] Test AV/screen setup — **Joe/Connor**
- [ ] Confirm room layout finalized — **Connor**
- [ ] Brief volunteer captain on run-of-show — **Connor**

---

## 🎬 Phase 4: Day Of Event

### Setup
- [ ] Confirm AV/sound tech on site — **Joe/Connor**
- [ ] WiFi info ready for crew (see [[Contacts/Credentials]])
- [ ] Room layout set (chairs, tables, screens) — **Volunteer crew**
- [ ] Food setup complete before doors — **Connor/food partner**

### Lobby & Facility
- [ ] Make sure parking QR code sign is out in lobby
- [ ] Put "Room Closed" sign on office door and classroom door
- [ ] Tidy sofas and ottomans (line up with window)
- [ ] Tidy rocking chair area
- [ ] Walk aisles — check for trash
- [ ] All trash cans empty
- [ ] If concessions: set up trashcans in lobby
- [ ] House music / visuals on lobby TVs
- [ ] Dim lobby lights once event begins

### Bathrooms
- [ ] Wipe down counters
- [ ] Empty trash
- [ ] Refill toilet paper
- [ ] Paper towels full

### Custodian
- [ ] Post custodian phone number: give to captain & staff; write on chalkboard
- [ ] Brief custodian: bathrooms and trash

### Volunteer Room (if applicable)
- [ ] Room Closed sign on door
- [ ] Coffee with fixings
- [ ] Hot water
- [ ] Snacks
- [ ] Water bottles or dispenser with ice water
- [ ] Volunteer lanyards
- [ ] *Break down after event midpoint if applicable*

---

## 🧹 Post-Event

- [ ] Dispose of food/trash; put leftovers away
- [ ] Leave green room, office, sofa area clean and tidy
- [ ] Remove any temporary event signage; store appropriately
- [ ] Break down and store tables and furniture
- [ ] Reset chairs if Sunday morning follows
- [ ] Check AVL; reset/restore to working order — **Joe**
- [ ] Walk building — confirm everyone is OUT
- [ ] Request pay for custodian — **Brian**
