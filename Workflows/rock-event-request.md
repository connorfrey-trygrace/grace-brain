# Workflow: Event Request Forms (Comms + Rock Registration)

## Purpose
How to fill out the two forms that stand up a Grace event: the **Grace Comms Request** (promotion/design) and the **Event Registration Request** (live sign-up link). Captures every field, the standard default, and where Connor's judgment is required.

## When to Use
- **Comms Request — always required for a non-service event.** Any event that isn't a regular service needs one.
- **Event Registration Request — always clarify first.** Many events need registration, but not all. Ask Connor whether this event requires a sign-up link before filling it.

## Hard Rules
- **Never submit either form without Connor's review.** Fill the fields, then summarize all values back to Connor and wait for explicit clearance. Connor submits or tells you to submit.
- **Prioritize internal consistency between the two forms.** Title/name, date, time, location, and the event summary/blurb must match across Comms and Registration. Rock's *Event Summary* field is explicitly "the same information included in your Comms Request Form."
- **Billing Code is almost always `8106` — always confirm with Connor anyway.**
- **Save the filled values (esp. the promo blurb) to a reusable doc.** Derek's standing recommendation, so similar future events can copy from it.

## Submission order (important)
**When an event needs both forms, submit Rock first, Comms second.** The Comms form's *Registration* field wants the live sign-up link, and that link doesn't exist until the Rock admin (Kay) processes the registration request and sends it back. So:

1. Submit the **Rock Event Registration Request** → Kay generates the live registration link and returns it.
2. **Then** submit the **Comms Request**, pasting that link into the Registration field.

If the event needs only the Comms form (no registration), submit it on its own and leave Registration blank.

## Process
1. Clarify with Connor: is this a non-service event (→ Comms required) and does it need registration (→ Rock form)?
2. Gather the shared facts once: name, date, start/end time, location, summary/blurb, cost.
3. Fill **both** forms from the shared facts — reuse the *same* title, date, time, location, and summary across them. Comms: confirm billing code `8106`. Rock: Account = "Event Registration"; reminder = 10 AM day before (interim).
4. **Summarize every filled value to Connor and wait for clearance. Do not submit until Connor approves.**
5. On approval, submit in order: **Rock first** → wait for Kay's live link → **Comms second** with the link in the Registration field.
