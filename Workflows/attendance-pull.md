# Workflow: Weekly attendance pull (Rock metrics → vault)

Keeps a copy of Grace's weekly adult attendance, by service time, in the vault so the Sunday Night trend can be tracked against the morning services and the same Sunday last year. Connor asked for it on 2026-11-11 ("an excellent indicator to track").

- **Source:** Rock › Reporting › Metrics, adult attendance at Ballston Quarter. Kay Carter-Corker sent the link on 2026-10-21: https://trygrace.rockcloud.com/reporting/metrics?MetricCategoryId=65&ExpandedIds=C193
- **Store:** [[Trackers/Attendance-Data.csv]] has one row per Sunday × service time. It is the canonical copy and stays append/upsert only.
- **View:** [[Trackers/Attendance]] is regenerated by the script every run. Never hand-edit it.
- **Script:** `python3 "Workflows/attendance-update.py"` with `stale` | `import FILE --source S` | `render`.

## When it runs

Runs as a **Phase 1 step of [[Workflows/grace-quick-refresh]]**, gated by a cheap check, so it costs nothing on most runs:

```
python3 "Workflows/attendance-update.py" stale
```

Exit 0 means the store already has the most recent Sunday, so skip the pull. Exit 1 means a Sunday is missing, so pull. Counts for a Sunday are expected by Monday. A pull on Sunday itself looks for the previous week.

## Pulling

1. In **Claude in Chrome**, open the metrics URL above. Rock needs Connor's sign-in. If the login page shows, stop and ask Connor to sign in, with "Keep me logged in" ticked. Never type credentials.
2. Read the values for every Sunday after the store's latest date. The fetch method is recorded below once it has been verified on a live pull.
3. Write them to a scratchpad TSV with columns `date<TAB>value<TAB>service` (for example `11/8/2026	70	Sunday 6:00pm`), then run:
   ```
   python3 "Workflows/attendance-update.py" import <tsv> --source "Rock metrics <YYYY-MM-DD>"
   ```
   The import upserts: a value Rock has since corrected prints as `changed …`. Mention any changed value in the report, because it means Kay or a volunteer edited history.
4. Dates are snapped to the Sunday on or before. Volunteers sometimes enter the 6 PM count on Monday; Rock shows the 10/4/2026 count under 10/5.

## Report

Add one line under "What changed" with the new Sunday(s): the 6 PM count and its 4-week average, plus anything notable such as a drop of more than 20% or a corrected value. The numbers stay in [[Trackers/Attendance]]; don't copy the table into the report.
