The vehicle used to access Power Pivot is Excel, but before we dive into this wonderful tool, Let's take a few moments to understand exactly what Power Pivot is. Power Pivot is an Excel add-in designed for advanced data analysis. It allows you to create complex data models, define relationships between tables, and perform calculations using something called DAX, which is an abbreviation for Data Analysis Expressions, typically best for large data sets. Now at this point you might be wondering, hang on, isn't that what Power Query does? The dynamic utility that everyone seems to be talking about? Look, not quite. Power Query is primarily used for data extraction, transformation, and data loading. It allows you to pull data from various sources such as databases, Excel files, web services, and like, and then clean, reshape, and transform the data before loading it into something like Excel or Power Pivot. In summary, Power Query is your best bet for sourcing and preparing data, whereas Power Pivot is best used after your data has been cleansed, allowing you to model and analyze it. The two utilities aren't competitors at all. Rather, they complement each other just like salt and pepper. In this course, we'll focus on Power Pivot. However, for more information on using Power Pivot alongside Power Query, feel free to explore the LinkedIn Learning Library. Power Pivot was first released back in 2010, and at the time was hailed as perhaps Excel's best new feature in a decade. Power Pivot natively integrates with Excel's standard features such as charts and pivot tables, but adds serious grunt to your data, enhancing your ability to produce insights, especially for large datasets. Oh, and I should mention that you must be using a PC version of Excel Desktop in order to access Power Pivot. Additionally, you must be using the desktop version of Excel, and not Excel for the web.
